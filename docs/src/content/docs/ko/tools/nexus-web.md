이 문서는 별도의 설정 없이 Nexus 웹 앱을 **사용**하기 위한 가이드입니다. 먼저 실행해야 하는 경우 [빠른 시작](/ko/tools/nexus/#실행-및-배포)을 참조합니다.

브라우저에서 `http://localhost:8000/`을 엽니다. Nexus는 **색인한 문서에서만** 질문에 답변하며, 모든 답변은 추측 없이 **출처와 함께** 제공됩니다.

## 질문하기 (채팅)

**채팅** 탭은 기본 인터페이스입니다. 자연어로 질문을 입력하고 전송을 누릅니다.

- **엔티티를 인용**하려면 `@name`(예: `@payment-service`)을 사용하여 특정 서비스나 엔티티에 검색을 집중시킵니다.
- 빈 화면에 **예시 질문**이 표시됩니다. 클릭하여 테스트해 봅니다.

## 답변 확인하기

모든 답변은 **근거를 기반으로 합니다**: 각 주장에는 `[source: document title, section]`과 같은 인용이 포함됩니다. 문서 제목은 파일 경로가 아닌 사람이 읽을 수 있는 이름입니다.

답변을 뒷받침하는 내용이 없으면 Nexus는 답변을 지어내는 대신 **제공된 문서에서 정보를 찾을 수 없음**을 알립니다. 이러한 거절이 핵심 동작입니다. Nexus는 정보를 결코 지어내지 않습니다.

## 답변 근거 패널

오른쪽 패널에는 답변의 바탕이 되는 **답변 근거**가 나열됩니다. 각 항목에는 다음이 표시됩니다:

- **문서 제목**,
- **신뢰도 배지**(아래 참조),
- **관련도 표시줄**(일치 강도, 백분율 표시), 및
- 일치하는 **텍스트 스니펫**.

하단의 **출처** 목록은 각 소스 문서를 제목별로 링크하며, 마우스를 올리면 원래 경로를 확인할 수 있습니다.

## 신뢰도 배지 — 소스 신뢰도 판단 기준

각 소스에는 거버넌스 등급이 태그로 지정되어 소스가 어느 정도의 비중을 갖는지 확인할 수 있습니다:

| 배지 | 의미 |
|---|---|
| **거버넌스** (녹색) | 검토 게이트를 통과한 승인된 표준 결정입니다(예: ADR, 설계 문서, RFC). 신뢰도가 가장 높습니다. |
| **추적** (주황색) | 검토되었으나 승인 게이트가 없습니다. drift 또는 노후화 여부를 주시해야 합니다(예: PRD, 런북, 사후 분석). |
| **메모** (회색) | 거버넌스 대상이 아닌 메모입니다. 유용한 참조 자료이지만 표준은 아닙니다(예: 가져온 메모). |

알 수 없거나 유형이 지정되지 않은 문서는 기본적으로 **메모**(보수적 기준)로 지정됩니다.

## 문서

**문서** 탭에는 Nexus가 색인한 모든 항목이 문서 유형별 신뢰도 배지와 함께 나열되므로 코퍼스의 거버넌스 상태를 한눈에 확인할 수 있습니다.

제목으로 검색하고 상태(색인됨 / 숨김 / Notion에서 삭제됨 / 대체됨)별로 필터링합니다. **출처** 열에는 문서가 Notion, 업로드, 파일 중 어디에서 비롯되었는지가 표시되며, Notion 문서는 해당 문서가 속한 페이지로 바로 연결되는 링크를 제공합니다.

**숨기기**를 하면 문서가 검색 대상에서 제외됩니다. 문서가 삭제되는 것은 아닙니다. 문서와 해당 청크는 유지되며, **되돌리기**를 통해 다시 복구할 수 있습니다. 확정하기 전에 확인 패널에 이 내용이 정확히 안내됩니다. 대체된 문서에는 해당 문서를 대체한 항목의 제목이 표시되며, 대체를 취소하려면 사유를 입력해야 합니다.

## 문서 추가 (업로드)

**업로드** 탭에서는 한 번에 하나씩 문서를 색인에 추가합니다.

## Notion 연결 (소스)

**소스** 탭에 Notion 페이지 URL을 붙여넣으면 해당 페이지의 전체 하위 트리가 검색 대상에 포함됩니다. 터미널이 필요하지 않습니다.

- 상단 패널은 **연결** 상태를 보고합니다. 토큰의 유효 여부, 해당 토큰이 속한 통합 및 워크스페이스를 표시합니다. 취소된 토큰은 녹색 표시 대신 해당 상태를 명시합니다.
- 등록된 각 루트에는 **접근 가능 여부**가 표시됩니다. Notion의 해당 페이지에 통합을 초대한 적이 없다면 동기화가 트리를 순회한 뒤가 아니라 여기에서 바로 확인할 수 있습니다.
- **지금 동기화**는 트리를 순회합니다. 최초 실행 시 사용합니다.
- Notion에서 삭제한 페이지를 검색 대상에서 제외하려면 먼저 **삭제 반영 미리보기**를 누릅니다. 제외될 대상이 제목별로 나열되며, 해당 목록을 확인할 때까지는 아무것도 적용되지 않습니다.

## 관계 탐색 (그래프)

**그래프** 탭에서는 그래프 데이터를 사용할 수 있을 때 문서 기반의 **설계된** 관계와 텔레메트리 기반의 **관측된** 엔티티 관계를 모두 표시합니다.

## 결과가 비어 있는 경우

액세스 토큰 없이 연결하면 Nexus는 **익명 모드**로 실행되며 **PUBLIC 문서만** 표시합니다. 이때 결과가 비어 있거나 일부만 표시되는 것은 보안 경계에 따른 동작이며 버그가 아닙니다. INTERNAL 콘텐츠를 보려면 토큰으로 로그인합니다.
