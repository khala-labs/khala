Khala 생태계의 생산자 도구군은 상호 직접 결합을 배제하고 **Khala 지식 공유 계층 및 프로토콜 규약**을 통해 데이터를 교환합니다. 개별적인 점대점(Point-to-Point) 결합을 방지하고 허브 중심의 단일 인터페이스 토폴로지를 유지합니다.

- **Archon**: 도메인 불변식 및 비즈니스 상수에 대한 단일 권위 창(Authority Window) 인터페이스를 제공하며, 정적 코드 상수와 직접 동기화됩니다.
- **Arbiter**: 검증 및 승인 완료된 아키텍처 사양(SPEC)을 Khala 공유 계층에 영속화하며, 사양의 진본성은 frontmatter 내 무결성 해시(Content Hash)를 통해 보장됩니다.
